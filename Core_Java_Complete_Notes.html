Even or Odd Parity Determination

Files: CheckEvenorOdd.java • CheckEvenOrOddMethod.java • EvenorOddMethod.java
Parity / Arithmetic Time: O(1) Space: O(1)
Detailed Definition & Core Concept
In number theory, parity refers to the attribute of an integer being either even or odd. An integer n is even if it is an exact multiple of 2 (i.e., n = 2k for some integer k), and odd if it leaves a remainder of 1 or -1 when divided by 2.

In Java, parity is calculated using the remainder operator % (modulo). Alternatively, it can be tested at the bitwise level via (n & 1) == 0, checking the least significant bit (LSB), which is 0 for even numbers and 1 for odd numbers.
Algorithmic Logic & Decision Flowchart

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int num = sc.nextInt();
        
        // Ternary operator evaluation of parity
        String result = (num % 2 == 0) ? "Even" : "Odd";
        System.out.println("The number is: " + result);
        sc.close();
    }
}
Execution Trace & Logic Walkthrough
  1. Read an integer input from the user via Scanner.nextInt().
  2. Evaluate condition num % 2 == 0: if true, value evaluates to 'Even'; otherwise 'Odd'.
  3. Print the computed string to the standard output console.

Expected Output
The number is: Even
Critical Edge Cases & Pitfalls
Zero: 0 % 2 == 0, properly identified as Even.
Negative Numbers: In Java, -3 % 2 evaluates to -1. Checking num % 2 != 0 correctly flags all odd integers regardless of algebraic sign.

Digit Extraction, Counting & Summation

Files: CountDigits.java • CountSumDigits.java • ReverseNumber.java
Arithmetic Decomposition Time: O(log10 N) Space: O(1)
Detailed Definition & Core Concept
Extracting the decimal digits of an integer relies on radix-10 arithmetic: 1. Extract LSB (last digit): digit = num % 10 2. Truncate LSB: num = num / 10

The number of iterations is proportional to the number of decimal digits: $\lfloor \log_{10}(N) \rfloor + 1$.
Algorithmic Logic & Decision Flowchart
CountDigits.java Java 17+ 
import java.util.Scanner;

public class CountSumDigits {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter an integer: ");
        int n = sc.nextInt();
        
        int temp = Math.abs(n);
        int count = (temp == 0) ? 1 : 0;
        int sum = 0;
        
        while (temp > 0) {
            int digit = temp % 10;
            sum += digit;
            count++;
            temp /= 10;
        }
        
        System.out.println("Total Digits: " + count);
        System.out.println("Sum of Digits: " + sum);
        sc.close();
    }
}
Execution Trace & Logic Walkthrough
  1. Take absolute value of input n to handle negative values.
  2. Extract rightmost digit via temp % 10.
  3. Add extracted digit to sum and increment count.
  4. Integer-divide temp by 10 to shift digits right.
  5. Repeat until temp == 0.
Sample Input
Enter an integer: 54321
Expected Output
Total Digits: 5\nSum of Digits: 15
Critical Edge Cases & Pitfalls
Input 0: Mathematically has 1 digit with sum 0. The ternary operator (temp == 0) ? 1 : 0 gracefully prevents reporting 0 digits.

Integer Reversal via Horner's Accumulator

Files: ReverseNumber.java
Arithmetic Transformations Time: O(log10 N) Space: O(1)
Detailed Definition & Core Concept
Reversing an integer mathematically without converting it to a string. Uses an accumulator initialized to 0. In each step, the existing reversed value is multiplied by 10 (shifting left) and the extracted digit is added: $$\text{rev} = (\text{rev} \times 10) + (n \% 10)$$
Algorithmic Logic & Decision Flowchart
ReverseNumber.java Java 17+ 
import java.util.Scanner;

public class ReverseNumber {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter number: ");
        int num = sc.nextInt();
        
        int rev = 0;
        while (num != 0) {
            int digit = num % 10;
            rev = (rev * 10) + digit;
            num /= 10;
        }
        
        System.out.println("Reversed Number = " + rev);
        sc.close();
    }
}
Execution Trace & Logic Walkthrough
  1. Initialize rev = 0.
  2. Extract last digit: digit = num % 10.
  3. Shift previous reversed digits left by multiplying by 10 and add the current digit.
  4. Divide num by 10.
  5. Terminate when num == 0.

Expected Output
Reversed Number = 54321
Critical Edge Cases & Pitfalls
Trailing Zeroes: An input like 1200 will output 21 (numerical value, since leading zeros are dropped in mathematical integers).

Compile-Time Polymorphism (Method Overloading)

Files: Overloadedadd.java • Overloadedarea.java • greet.java
Polymorphism / Signatures Time: O(1) Space: O(1)
Detailed Definition & Core Concept
Method overloading allows a class to define multiple methods with the exact same name, provided their parameter lists differ in: 1. Number of parameters (e.g., add(int, int) vs add(int, int, int)) 2. Data types of parameters (e.g., add(int, int) vs add(double, double)) 3. Sequence of parameter types.

Note: Overloading is resolved strictly at compile time based on parameter types. Varying the return type alone does NOT constitute a valid overload.

Detailed Definition & Core Concept
Finding the second largest element in an unsorted array without sorting ($O(N \log N)$).

Using two tracker variables (first and second), we inspect each element $x$ in a single pass: 1. If $x > \text{first}$, the former first cascades down to become second, and first takes $x$. 2. Else if $x > \text{second}$ and $x \neq \text{first}$, update second = x.
Algorithmic Logic & Decision Flowchart

public class FindtheSecondLargestNumber {
    public static int findSecondLargest(int[] arr) {
        if (arr == null || arr.length < 2) return -1;
        
        int first = Integer.MIN_VALUE;
        int second = Integer.MIN_VALUE;
        
        for (int num : arr) {
            if (num > first) {
                second = first;
                first = num;
            } else if (num > second && num != first) {
                second = num;
            }
        }
        
        return (second == Integer.MIN_VALUE) ? -1 : second;
    }

    public static void main(String[] args) {
        int[] arr = {12, 35, 1, 10, 34, 1};
        System.out.println("Second Largest: " + findSecondLargest(arr));
    }
}

  2. Iterate through each element num in the array.
  3. If num > first, update second = first, then first = num.
  4. Else if num > second and num != first (skip duplicate firsts), update second = num.
  5. If second remained untouched, return -1 (no distinct second largest).

public class ReverseanArray {
    public static void reverse(int[] arr) {
        int left = 0;
        int right = arr.length - 1;
        
        while (left < right) {
            // In-place swap using temporary variable
            int temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;
            
            left++;
            right--;
        }
    }

        reverse(arr);
        System.out.println("Reversed: " + Arrays.toString(arr));

Array Cyclic Rotation by K Offsets

Files: RotateByArray.java

Detailed Definition & Core Concept
Rotating an array to the right by $k$ positions moves the last $k$ elements to the front.

The 3-Step Inversion Algorithm (Optimal $O(N)$ time, $O(1)$ space): 1. Normalize $k = k \% N$. 2. Reverse the entire array from index $0$ to $N - 1$. 3. Reverse the first $k$ elements from index $0$ to $k - 1$. 4. Reverse the remaining $N - k$ elements from index $k$ to $N - 1$.
Algorithmic Logic & Decision Flowchart
RotateByArray.java Java 17+ 
import java.util.Arrays;

public class RotateByArray {
    public static void rotate(int[] arr, int k) {
        int n = arr.length;
        if (n <= 1) return;
        k = k % n;
        
        reverse(arr, 0, n - 1); // Reverse whole array
        reverse(arr, 0, k - 1); // Reverse first k
        reverse(arr, k, n - 1); // Reverse remaining
    }
    
    private static void reverse(int[] arr, int start, int end) {
        while (start < end) {
            int temp = arr[start];
            arr[start++] = arr[end];
            arr[end--] = temp;
        }
    }

    public static void main(String[] args) {
        int[] arr = {1, 2, 3, 4, 5, 6, 7};
        rotate(arr, 3);
        System.out.println("Rotated by 3: " + Arrays.toString(arr));
    }
}

  2. Perform 3 targeted reversals in place.

        int i = 0, j = 0, k = 0;
        
        while (i < a.length && j < b.length) {
            if (a[i] <= b[j]) {
                res[k++] = a[i++];
            } else {
                res[k++] = b[j++];
            }
        }
        
        while (i < a.length) res[k++] = a[i++];
        while (j < b.length) res[k++] = b[j++];
        
        return res;

Detailed Definition & Core Concept

For a node $N$, the recursive call reverses the tail. Upon return: $$N.\text{next}.\text{next} = N$$ $$N.\text{next} = \text{null}$$ This makes the next node point backward to the current node, cleanly inverting the pointer direction.
Algorithmic Logic & Decision Flowchart

public class ReverseaLinkedListUsingRecursion {
    static class Node {
        int data;
        Node next;
        Node(int data) { this.data = data; }
    }

    public static Node reverseList(Node current) {
        // Base case: empty list or reached terminal node
        if (current == null || current.next == null) {
            return current;
        }

        // Recursive call down to the last node
        Node newHead = reverseList(current.next);

        // Reverse connection: make successor point back to current
        current.next.next = current;
        current.next = null; // Sever old forward link

        return newHead;
    }

    public static void main(String[] args) {
        Node head = new Node(1);
        head.next = new Node(2);
        head.next.next = new Node(3);
        
        Node rev = reverseList(head);
        while (rev != null) {
            System.out.print(rev.data + " -> ");
            rev = rev.next;
        }
        System.out.println("null");
    }
}
Execution Trace & Logic Walkthrough
  1. Recursively advance until reaching the final node (which becomes the new head).
  2. At each stack level during unwinding, set current.next.next = current.
  3. Sever existing forward link: current.next = null.
  4. Propagate newHead back to the initial caller.

import java.util.Map;

public class TwoSum {
    // One-pass Hash Table Solution
    public static int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {

        }
        return new int[] {-1, -1};
    }

    }
}

Algorithmic Logic & Decision Flowchart
MaximumSumSubarrayK.java Java 17+ 
public class MaximumSumSubarrayK {
    public static int maxSubarraySum(int[] arr, int k) {
        if (arr.length < k) return -1;
        
        // Sum of initial window
        int windowSum = 0;
        for (int i = 0; i < k; i++) {
            windowSum += arr[i];
        }
        
        int maxSum = windowSum;
        // Slide the window across remainder of array
        for (int i = k; i < arr.length; i++) {
            windowSum += arr[i] - arr[i - k]; // Add incoming, drop outgoing
            maxSum = Math.max(maxSum, windowSum);
        }
        
        return maxSum;
    }

    public static void main(String[] args) {
        int[] arr = {2, 1, 5, 1, 3, 2};
        int k = 3;
        System.out.println("Max Sum Subarray of Size " + k + " = " + maxSubarraySum(arr, k));
    }
}

  2. Initialize maxSum = windowSum.
  3. Slide window from index $k$ to $N - 1$, adjusting by $+arr[i] - arr[i - k]$.
  4. Update maxSum with the maximum value seen.
  5. Return maxSum.
